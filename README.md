# 手写数字识别（3 隐藏层 MLP + 平板输入）

用**纯 NumPy** 实现的教学级项目：一个 3 个隐藏神经元层的多层感知机，识别 MNIST 手写数字（0–9），并提供一个**支持平板触摸/手写笔**的网页画板，画完即预测。

网络结构与《三层网络识别手写数字_教学文档.md》完全对应：

```
输入(784) → 隐藏①(256, ReLU) → 隐藏②(128, ReLU) → 隐藏③(64, ReLU) → 输出(10, softmax)
```

代码里的每一行都能和文档中的公式对上（见 `model.py` 注释），适合边读代码边学原理。

> **本交付包已包含训练好的 `model.npz`（测试集准确率 98.06%），可跳过「3. 获取素材 / 4. 训练」直接 `python app.py` 使用。** 想自己重训再按下面步骤来。

## 1. 项目结构

```
mnist_mlp/
├── model.py          # MLP 定义：forward / backward / save / load（纯 NumPy）
├── download_data.py  # MNIST 自动下载（多镜像回退）
├── train.py          # 训练脚本
├── app.py            # 推理后端（标准库 http.server，无需 Flask）
├── index.html        # 前端画板（Canvas + 触摸，平板可用）
├── requirements.txt  # 仅 numpy
├── data/             # MNIST idx 文件（首次运行自动下载）
├── model.npz         # 训练好的权重（训练后生成）
└── train_log.json    # 每轮准确率（训练后生成）
```

## 2. 安装

本项目提供**便携版**：`runtime/` 目录已内置完整 Python + numpy，整个文件夹拷到任意 **x64 Windows** 机器，**无需安装任何东西**，双击 `run.bat` 即可运行（详见第 8 节）。

若你更想用自己机器上的 Python（需 3.10+）：

```bash
python -m venv venv && venv/Scripts/activate
pip install numpy
```

## 3. 获取训练素材（MNIST）

直接跑训练脚本会自动下载；也可单独下载：

```bash
python download_data.py
```

脚本依次尝试 torchvision 官方 S3 镜像、GitHub cvdfoundation 镜像，**自动换源**，最终在 `data/` 生成 4 个 idx 文件。

> 手动下载：从 https://github.com/cvdfoundation/mnist 取 4 个 `.gz` 解压到 `data/` 也可。

## 4. 训练

```bash
python train.py                 # 默认 20 轮 / batch 128 / lr 0.1
# 可选参数
python train.py --epochs 30 --batch 256 --lr 0.05
```

训练完成后生成 `model.npz`，并在测试集上报告准确率（3 隐藏层通常 **97%–99%**）。

## 5. 启动并平板使用

```bash
python app.py                   # 默认端口 8000
```

终端会打印两个地址：

- 本机：`http://localhost:8000`
- **平板**：`http://<电脑局域网IP>:8000`（平板与电脑连同一 WiFi）

在平板浏览器打开该地址，用**手指或手写笔**在黑底画板上写数字，点「预测」即可看到结果与 0–9 的概率条。

> 平板适配要点：`index.html` 用 **Pointer Events** 统一鼠标/触摸/笔，并设 `touch-action: none` 防止书写时页面滚动。

## 6. 常见问题

- **画了没反应 / 连不上**：必须用 `python app.py` 启动后通过 `http://IP:8000` 访问，直接双击打开 `index.html`（file://）无法调用 `/predict`。
- **识别不准**：尽量把数字写在画板**中央**、笔画连贯；前端已自动做 MNIST 风格预处理（裁剪居中到 28×28）。
- **想换网络深度/宽度**：改 `train.py` 里 `MLP(sizes=(784,256,128,64,10))` 即可，前后端无需改动。

## 6.1 网络连线可视化（教学增强）

右侧面板把网络画成 **5 列节点 + 链接线**：

- 输入（28×28 缩略图）→ 3 个隐藏层 → 输出（10 类）。
- **节点颜色越深 = 该神经元激活越强**；**连线越明显 = 信号流向被激活的神经元**（隐藏层 256→128→64 为示意采样，并非全量，但直观呈现「全连接」结构）。
- 输出列每个节点标注数字，右侧概率条是该类的得分，预测结果带高亮环。

画完点「预测」即实时点亮每一层，学生可直观看到数据从输入逐层流向输出、哪些神经元被「点亮」。

## 6.2 纠错学习（记住错误并就地更新）

识别错了？在右侧「点选正确数字」，模型会把这个样本**记住**并就地更新权重（增量学习），下次遇到类似写法会更准。

实现要点：

- 后端 `/learn` 对该样本做几步小学习率 SGD（`model.learn_example`，复用 forward/backward 梯度），并配合**经验回放**（随机重学几个历史纠错）防止「灾难性遗忘」。
- 纠错样本存入 `corrections.npz`，**基础模型 `model.npz` 保持不动**。每次启动会回放所有纠错样本重建个性化模型，结果可复现、可重置。
- 「重置个性化学习」按钮调用 `/reset_learn`，清空记忆并恢复基础模型。

> 注意：单样本增量学习是教学演示用的「记住」机制，少量纠错能改善对应写法；大量纠错可能略微影响整体精度，需要时点「重置」即可回到原始 98% 模型。
